# Test Plan
Generated by /ship on 2026-08-22
Branch: Divyank
Repo: NitishKumar-ai/odoo-dayflow

## Affected Pages/Routes
- `/signin` — verify demo-account selection fills both controlled fields, password visibility toggles, errors preserve input, and submission reaches the sign-in action.
- `/signup` — verify every live password rule, employee/admin role guidance, rejected submission preservation, and successful registration.
- `/dashboard` — verify attendance status cards and zero-data states for employees and administrators.
- `/attendance` and `/admin/attendance` — verify all clock states, leave state, action errors, and admin overrides.
- `/leave` and `/admin/leave` — verify working-day calculations, quota warnings, request submission, withdrawal, and approval/rejection states.
- `/payroll` and `/admin/payroll` — verify salary arithmetic, invalid numeric input, zero floor, save errors, and empty payroll states.
- `/profile` — verify controlled contact fields, successful updates, rejected updates, and empty avatar fallback.

## Key Interactions to Verify
- Select each demo account on `/signin`, then submit and confirm the selected role lands on the correct dashboard.
- Toggle password visibility without losing the entered password.
- Enter passwords on `/signup` that independently satisfy and fail each displayed requirement.
- Clock in, clock out, and observe the disabled/on-leave/day-complete states.
- Change leave dates in both orders and confirm the end date is corrected and working days exclude weekends.
- Edit salary inputs and confirm gross/net previews match submitted values.
- Edit phone, address, and photo URL, then verify server errors leave all entries intact.

## Edge Cases
- Empty, reversed, weekend-only, one-day, and over-balance leave ranges on `/leave`.
- Double-submit, slow action, expired session, and server failure for every server-action form.
- Missing check-in time with a check-out time, approved leave with stale attendance data, and repeated clock actions.
- Empty, negative, decimal, and non-numeric salary fields on `/admin/payroll`.
- Empty datasets and long employee names/addresses on dashboard, employee, attendance, leave, payroll, and profile pages.
- 375px viewport with no horizontal document overflow across all changed routes.

## Critical Paths
- Demo account selection -> sign in -> role-specific dashboard -> sign out.
- Employee clock in -> attendance row update -> clock out -> completed-day state.
- Employee leave request -> admin decision -> employee balance/status update -> withdrawal where allowed.
- Admin salary edit -> payroll calculation -> employee payroll display.
- Signup -> email verification -> first sign in.
