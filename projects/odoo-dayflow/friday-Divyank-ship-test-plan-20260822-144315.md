## Affected Pages/Routes
- /admin/project — NEW. Admin-only delivery roadmap. Verify non-admin is redirected, counts match roadmap data.
- /dashboard — stat cards, weekly heatmap, leave meters, admin command center.
- /attendance, /admin/attendance — check-in/out widget, weekly matrix, HR override row.
- /leave, /admin/leave — balance meters, request timeline, approval filter tabs + badges.
- /payroll, /admin/payroll — SalaryCard composition bar, live-calculating SalaryForm.
- /profile, /admin/employees, /admin/employees/[employeeId] — profile editor, directory, employee 360.
- /signin, /signup, /verify-email — password checklist, visibility toggle, verification flow.

## Key Interactions to Verify
- Nav "Project" entry appears for admins only and highlights on /admin/project.
- Clock in then clock out; duration counts up live; state persists on reload.
- Leave form duration recalculates as dates change; weekend handling matches src/lib/leave.ts.
- SalaryForm gross/net recalculate as fields change; submit creates a revision.
- AttendanceOverride select keeps its chosen value after the action settles (useFields regression).
- Approval filter tabs update counter badges without a full reload.

## Edge Cases
- Zero-entitlement leave type renders 100% available, not NaN.
- Salary with all-zero earnings renders 0% components, not NaN.
- Over-granted leave balance clamps the meter at 100%.
- Nav badge of 0 renders no badge.
- Employee with no salary structure on /payroll.
- Attendance page with no records for the week.

## Critical Paths
- Sign up -> verify email -> sign in -> land on dashboard.
- Employee requests leave -> HR approves -> attendance reflects the approved leave.
- HR edits salary -> employee sees the new structure and the revision trail.
- Admin overrides an attendance status -> the override persists and is attributed.
