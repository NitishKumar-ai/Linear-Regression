## Problem Statement
Developing a disaster response intelligence platform for flood prediction, emergency planning, and resource allocation for the Decode SIH 2026 hackathon (BHARAT SHAKTI track). 

## What Makes This Cool
The "whoa" factor is the combination of an AI routing engine and an offline "BitChat architecture" (BLE mesh networking + Nostr) that handles coordination even when cell towers fail during a flood, taking inspiration from Japan's SIP4D and FEMA's agentic AI.

## Constraints
- 50-day hackathon timeline
- Needs to integrate partner tech (Render, n8n, Lyzr/Swytchcode) for prizes
- Must be demo-able with two phones and a laptop

## Premises
1. The Core Hackathon Value: The main wow factor is true offline resilience (BLE Mesh) combined with AI routing.
2. Hardware Constraints: Field responders will have smartphones running a background BLE mesh app (React Native).
3. Distribution: Web App on Render for Command Dashboard, React Native app for field responders.

## Recommended Approach (Revised in Eng Review)
APPROACH A: The BitChat Architecture (BLE Mesh). We are pivoting away from a simulated PWA mesh to a true React Native BLE Mesh app. The Command Dashboard remains Next.js, and the backend is FastAPI powered by SQLite for speed. WebSockets will provide instant updates to the dashboard when a mesh ping hits an internet-connected gateway.

## NOT in scope
- Full PostgreSQL deployment (deferred to save hackathon time; using SQLite).
- Advanced SLM intelligence on edge devices (deferred to focus on BLE mesh stability).
- Cross-platform Swift/Kotlin native apps (using React Native to unify the codebase).

## What already exists
- React Native BLE-PLX libraries can provide the baseline for the mesh.
- WebSockets in FastAPI are native and will easily power the real-time dashboard.

## Failure modes
1. BLE Mesh packet drops: Handled by store-and-forward logic in the React Native app.
2. SQLite write locks: Mitigated by using WAL mode in SQLite for concurrent reads.
3. WebSocket disconnects: The Next.js dashboard will implement exponential backoff reconnection.

## Distribution Plan
Web service (FastAPI + Next.js) deployed on Render. React Native app sideloaded onto demo Android/iOS devices.
