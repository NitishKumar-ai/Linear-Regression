## Problem Statement
The rise of AI coding tools has created a new class of builders ("vibe coders") who ship complex apps without traditional SWE backgrounds. They need a dedicated platform to showcase their unique workflow, the tools they use, and how they solve problems alongside AI.

## What Makes This Cool
The "Vibe Coding Journey" timeline. It doesn't just show the final app; it visualizes exactly how human intelligence collaborated with the LLM to solve the problem, complete with model names and prompt flows. It also features "Gem," an AI assistant that helps builders actually learn the stack as they build.

## Constraints
This is a hackathon project, so time is strictly limited. We must prioritize a working MVP that delivers a shareable link over complex social or feed features.

## Premises
1. The real value is exposing the human-LLM workflow, not just hosting a final app. If we hide the prompts/process, the product fails its core mission.
2. The MVP must prioritize the fastest path to a shareable public link over complex social feed features.
3. Users of this platform actively want to learn the underlying tech stack; they aren't just looking for a pure black-box AI generator.

## Approaches Considered
### Approach A: The Minimal Static Generator (Fastest MVP)
A simple React/Next.js frontend that renders a JSON file of the vibe coding journey into a beautiful static timeline profile page. No backend required.
### Approach B: The Full-Stack Portfolio App (Ideal Architecture)
A Next.js app with Supabase (auth/db) where users log in, connect GitHub, and let a background LLM draft their vibe coding timeline to a public profile.
### Approach C: The IDE Plugin + Web Viewer (Creative/Lateral)
A VS Code extension that silently records prompts and code iterations in real-time, publishing 100% authentic proof-of-work traces to a web viewer.

## Recommended Approach
Approach B: The Full-Stack Portfolio App (Ideal Architecture). This provides the true "LinkedIn" experience and supports the "Gem" learning assistant integration.
