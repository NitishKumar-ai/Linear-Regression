## Edge Cases & Robustness
- **Float comparison**: Use `pytest.approx()` for all state value assertions to bypass minor CPU differences.
- **Stochastic seeding**: Use fixed seeds for random capability noise injections to make tests deterministic.
- **Boundaries**: Epoch clamping test ensuring values never overshoot 1.0 or drop below 0.0 under extreme difference iterations.
- **Multiprocessing safety**: Assert no pyplot leaks and verify parallel coordinate calculations do not cause locks.
- **Incremental disk writes**: Run massive mock coordinates grids and verify memory usage remains bounded.

## Critical Paths
- Quickstart CLI Run: `python main.py --preset naive` executes successfully, producing a Markdown summary `out/naive_summary.md` and SVG charts `out/naive_charts/*.svg` in under 5 seconds.
- Library API Usage: Jupyter notebook import runs the simulation loop programmatically with custom parameters.
- Multi-core sweep: `python main.py --sweep 10` distributes grid cells parallelly, exports a single CSV file, and cleans up temp folder allocations.
