# Test Plan

## Affected Pages/Routes
- POST /auth/token — login with form credentials; returns JWT + role
- GET /auth/me — current user info from token
- POST /auth/users — admin-only user creation with role validation
- POST /videos — upload with extension/size validation, camera_id, Celery dispatch
- GET /videos — authenticated listing
- GET /videos/{id}/clip — ffmpeg clip cutting with LRU cache
- GET /search — semantic search with inline NL filters (camera:/object:/after:/before:)

## Key Interactions to Verify
- Login round-trip: seed user → login → token works on protected route
- Role matrix: viewer blocked from upload (403) and user-create (403)
- NL filter precedence: explicit query params beat inline filters
- Object filter prune: Qdrant hits without a DetectedObject within ±2s are dropped
- Clip caching: second identical request skips ffmpeg

## Edge Cases
- Expired/malformed/no-sub/deleted-user tokens → 401
- Invalid time expressions (after:abc) parse to None silently
- Upload .txt → 400; oversize → 413 with partial-file cleanup
- Clip duration clamped to 60s; raw file missing → 404
- Qdrant down → 503; CLIP model unavailable → 503

## Critical Paths (E2E only — Docker compose stack, see test-plan.md)
- Upload → Celery → CLIP/YOLO/Whisper → Qdrant+Postgres → searchable, status=indexed
- Retry exhaustion → status=failed
- Audit log persistence across login/upload/search
