## Key Interactions to Verify
- Upload a valid text-based PDF → questions generated within 30s → copy-all to clipboard works
- Upload a scanned PDF (image-only) → Gemini handles it via vision → questions generated
- Upload a non-PDF file (e.g. .docx) → 400 error with clear message shown to user
- Upload PDF > 10MB → 400 error with file size message
- Submit without a file → 400 error before Gemini is called
- Gemini fails/times out → clear error message on screen (not a blank page)
- Submit 6 requests in 1 minute from same IP → 6th gets 429 rate limit error

## Edge Cases
- PDF with only 1 page of content → request numQuestions=20, Gemini should return fewer
- PDF with mixed Hindi + English text → questions generated in English (subject to Gemini behavior)
- numQuestions not provided in request body → 400 Zod validation error
- numQuestions=0 or negative → 400 Zod validation error
- Gemini returns some malformed MCQs (missing 4th option) → those are filtered, valid ones returned
- All MCQs malformed → 422 "Could not generate valid questions from this PDF"
- DB unavailable during session tracking → request still succeeds (fire-and-forget pattern)

## Critical Paths
- Upload Physics NCERT chapter PDF → 15+ valid MCQs returned within 30 seconds
- Rate limit fires correctly for no-auth endpoint (IP-based)
- Gemini timeout after 30s → clean 504 error with user-facing message
