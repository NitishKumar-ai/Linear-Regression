## Affected Routes/Endpoints
- `POST /webhook` — receives GitHub push/PR events, verifies HMAC, enqueues review task

## Test Modules (pytest)

### Unit Tests — Pure Functions (tests/test_security.py)
- `test_hmac_valid_signature`: valid X-Hub-Signature-256 header returns True
- `test_hmac_invalid_signature`: tampered payload returns False → 401
- `test_hmac_missing_header`: missing header returns False → 401
- `test_hmac_empty_secret`: empty webhook secret raises ConfigError

### Unit Tests — Diff Truncation (tests/test_truncation.py)
- `test_truncate_under_limit`: diff < 40K chars passes through unchanged
- `test_truncate_at_exact_limit`: diff == 40000 chars passes through unchanged
- `test_truncate_over_limit`: diff > 40K chars is truncated at file boundary (not mid-hunk)
- `test_truncate_single_large_file`: single file > 40K chars: truncated at 40K
- `test_truncate_preserves_hunk_structure`: truncated diff is still valid unified diff format

### Unit Tests — Event Routing (tests/test_webhook.py)
- `test_event_type_pull_request_opened`: enqueues review task
- `test_event_type_push`: enqueues review task
- `test_event_type_issue_comment`: returns 200 without enqueuing (ignored event)
- `test_event_type_ping`: returns 200 (GitHub app installation handshake)

### Mock-Based Integration Tests — plan→execute→review (tests/test_review_pipeline.py)
Mocked: LLM clients (Flash-Lite + Sonnet), E2B session, GitHub API client

- `test_plan_decomposes_diff_into_segments`: verify Plan type returned with List[Segment]
- `test_execute_secret_found_via_trufflehog`: mock truffleHog finding → Result with HIGH finding
- `test_execute_no_secrets_found`: clean diff → Result with empty findings
- `test_execute_e2b_timeout_skips_segment`: E2B timeout → segment skipped, review continues
- `test_review_aggregates_findings`: multiple Result inputs → Verdict with worst severity
- `test_review_passed_when_clean`: zero findings → Verdict.passed = True
- `test_review_failed_on_critical`: CRITICAL finding → Verdict.passed = False
- `test_full_pipeline_end_to_end_mocked`: full plan→execute→review with all mocks → comment posted

### Mock-Based Integration Tests — Error Recovery (tests/test_error_recovery.py)
- `test_github_api_404_on_diff_fetch`: PR deleted before review → silent abort, no crash
- `test_llm_timeout_in_plan_pass`: Flash-Lite timeout → abort, no review comment posted
- `test_llm_timeout_in_review_pass`: Sonnet timeout → abort, no partial comment posted
- `test_github_403_on_comment_post`: no write permission → logged, no crash

### E2E Tests — Real GitHub Interaction (tests/test_e2e.py)
Requirements: GITHUB_TEST_REPO env var (a dedicated test repo), GITHUB_PAT, all LLM API keys

- `test_webhook_to_comment_posted`: open a real PR with a known secret → verify CommitGuard 
  comments with CRITICAL finding within 120s
- `test_no_duplicate_comment_on_retry`: simulate GitHub webhook retry (same delivery) → verify 
  only 1 comment is posted (idempotency guard)
- `test_large_pr_truncation_noted`: open a real PR with >40K diff → verify comment notes truncation

## Key Interactions to Verify
- HMAC verification rejects tampered payloads before any processing
- 40K truncation happens at file boundary (not mid-hunk) to avoid malformed diffs
- Duplicate reviews are blocked (check existing CommitGuard comment before posting)
- Background task failures are logged but do not crash the webhook server

## Edge Cases
- PR with 0 changed files (empty diff) → no review, no comment
- PR with only binary files (no text diff) → no review, no comment  
- GitHub webhook retry after 200 already sent → idempotency guard fires
- All E2B sessions fail → review aborts cleanly, no partial comment posted
- LLM returns malformed response (not valid JSON for structured output) → retry once, then abort

## Critical Paths (must pass before any user gets access)
1. HMAC verification correctly rejects all invalid signatures
2. plan→execute→review loop produces a Verdict for a diff with a known secret
3. E2E: real GitHub PR → real review comment within 120 seconds
