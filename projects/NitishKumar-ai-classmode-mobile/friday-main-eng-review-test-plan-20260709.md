## Affected Pages/Routes
- `(public)/login` — email+password states: 401 wrong creds, 403 not-active, 429 rate-limited, offline, 5xx; forgot-password opens web reset in system browser
- `(app)/index` (teacher home) — receipt card pre/post marking; all-classes list sorted by marking status; pending-sync chip
- `(app)/attendance` (marking + History tab) — default-present roster, tap absent, long-press late/excused, mark-all-present, Saved·Undo, 3-day backfill limit, honest alert copy (enabled vs disabled school)
- `(app)/people` (parent) — unlinked claim screen (wrong code / phone mismatch / already claimed / unverified email resend), child today status incl. "not marked yet" morning state, monthly % chip
- `(app)/school` (principal) — pre-marking expectation state, coverage by class, unmarked-class chase list, honest empty
- Server: POST /api/attendance (W-2/W-6), /api/auth login/refresh (W-1), /api/parent (W-3), aggregates (W-4)

## Key Interactions to Verify
- Mark a class fully offline (airplane mode) → relaunch app → reconnect → rows appear server-side exactly once, one alert max per (student, date)
- Undo within 5s of submit → no parent alert dispatched (server-side test)
- Double-tap submit → single request (button disabled in-flight)
- 5 concurrent 401s → exactly one refresh call (single-flight)
- Refresh returns 5xx/429 → tokens kept, banner shown, retry succeeds later
- Logout on mobile → subsequent requests 401 (no cookie-jar resurrection; no Set-Cookie ever sent to mobile client)
- Cross-school studentId in mark payload → 403 (W-6 authz)
- DB failure during mark → non-200; client keeps queue item

## Edge Cases
- Cold start offline with stored tokens → cached session + offline banner, zero unscoped fetches
- null schoolCode (any non-admin role) → blocked state, no data fetch (fail-closed invariant)
- `school_code` snake_case mapping — /me parse test (silent undefined = whole app blocked)
- Stale replay: offline mark from 8:00 flushed at 11:00 after a 10:00 web correction → server skips (markedAt < updated_at)
- Roster with 0 students; class list empty ("no classes assigned")
- Biometric: not enrolled → gate skipped; hardware fail → device-credential fallback
- 30 devices on one school NAT within a minute → no 429 on /me + /refresh (staging with NODE_ENV=production)

## Critical Paths
- Teacher: login → mark class in <20s → receipt card shows marked state all day
- Parent: claim child via school code → morning "not marked yet" → status flips when teacher marks
- Principal: 9am dashboard shows expectation-framed coverage + chase list, never fabricated numbers
